# Drops Studio product contract

## Product promise

Drops Studio turns a crypto idea into a working, editable and publishable product powered by DropsTab data/research primitives and Drops Bot automation/action primitives. It is not a gallery of mockups and it is not a generic prompt wrapper.

## Competitive product loop

1. **Choose or describe** — start from the approved preset carousel or a blank prompt.
2. **Direct** — Free Director converts intent into a product brief, user loop, required Drops primitives, art direction, screens and success checks.
3. **Compare** — generate and compare curated visual directions without modifying the working version.
4. **Build** — compile a real standalone product with deterministic behavior and safe data contracts.
5. **Edit** — chat proposes bounded changes; selected elements expose direct text, color, spacing, visibility and variant controls.
6. **Review** — show the exact proposed changes before Apply; every accepted change creates a checkpoint.
7. **Test** — run the primary product interaction inside the preview and show its current data/source state honestly.
8. **Publish** — create a public working URL on the free hosting path.
9. **Own** — export a runnable ZIP with source, configuration and hosting workflows; advanced Git sync remains an upgrade path.

## Free core

- All product presets and blank-project mode
- Free crypto-aware Director
- Curated design kits and free vector/game asset packs
- Direct visual edits and contextual chat proposals
- Checkpoints, undo and local project history
- DropsTab-compatible market-data adapter and saved fallback snapshot
- Drops Bot deep-link and approval handoffs
- Free public URL, share flow and runnable source ZIP
- BYO OpenAI, Claude, OpenRouter, Kimi or compatible API key (session only)

## Professional upgrades

- Generated image/video/sprite packs
- Long-running agent tasks and deeper cross-file changes
- Team collaboration and extended history
- Two-way Git sync, branches, commits and pull requests
- Custom domains, analytics and professional hosting providers

The free path must remain capable of producing and publishing a useful product.

## Category quality bar

A generated product must visually and behaviorally match its category. In particular, Crypto Game requires an illustrated world, characters, animation, game state, an actual repeatable loop, score/streak, challenges and share behavior. A data table with a prediction button does not qualify as a game.

The same depth applies to every category. Aggregators need real ranking/filter/view/page controls; briefs and channels need editorial structure, voice, scheduling and action cards; decision, prediction and copy products need graphs, triggers, risk gates, simulation and audit; media/community products need feed, moderation, monetization and social loops; assistants and companions need personality, memory, recommendations, voice and state. Crypto Game is a benchmark, not a special exception.

## Release acceptance

- Create -> Director -> Apply -> visual edit -> chat edit -> Undo works.
- Every preset has a distinct primary interaction that persists state where relevant.
- Game feels like a game on desktop and mobile and finishes a complete round.
- Publish returns a public URL that works without editor state or API keys.
- Exported ZIP runs and contains source plus deployment configuration.
- Connected model errors are honest and never break the free fallback.
- Typecheck, lint, tests, CodeRabbit review and browser QA pass before release.
